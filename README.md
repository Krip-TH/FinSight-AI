# FinSight-AI

ต้นแบบสำหรับอ่าน สรุป ถามตอบ และเปรียบเทียบเอกสารการเงินพร้อมหลักฐานหน้า PDF
ใช้ React + Tailwind CSS / FastAPI / PyMuPDF / SQLite / Gemini
ไม่ทำนายราคาและไม่ให้คำแนะนำซื้อขาย

## เปิดใน VS Code

เปิดโฟลเดอร์ repository นี้ด้วย File → Open Folder และเปิด Terminal ที่โฟลเดอร์หลัก
ต้องมี Python 3.12 หรือ 3.13, Node.js 22 และ Git

ติดตั้งครั้งแรกบน Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm --prefix frontend ci
```

## เปิดเว็บด้วยขั้นตอนเดียว

ดับเบิลคลิก `Run-Web.cmd` ในโฟลเดอร์โปรเจกต์ ระบบจะเปิด Backend และ Frontend พร้อมกัน แล้วเปิดเว็บให้อัตโนมัติเมื่อพร้อมใช้งาน
แก้โค้ดแล้วหน้าเว็บและ Backend โหลดใหม่ได้ ไม่ต้องสั่ง Build ทุกครั้ง

หรือเปิด Terminal ใน VS Code แล้วรัน:

```powershell
.\Run-Web.cmd
```

ใน VS Code กด **Ctrl+Shift+B** หรือ Terminal → Run Task → **Run: FinSight web** เพื่อเปิดทั้งสองส่วนด้วยกัน
หน้าเว็บอยู่ที่ http://127.0.0.1:5173 และ Backend อยู่ที่ http://127.0.0.1:8000
หยุดทั้งสองส่วนด้วย **Ctrl+C** ใน Terminal ที่เปิดเว็บ ไม่ต้องปิดแยกสองหน้าต่าง

ต้องติดตั้งตามขั้นตอนครั้งแรกด้านบนก่อน หากพอร์ตถูกใช้งาน ระบบจะแสดงปัญหาโดยไม่ปิดโปรแกรมอื่น
เลือกพอร์ตอื่นได้ เช่น:

```powershell
.\Run-Web.cmd --backend-port 8002 --frontend-port 5174
```

ตัวเปิดตรวจ Backend, Frontend และ API proxy ก่อนเปิดเบราว์เซอร์ ใช้ `--no-browser` หากต้องการเปิดเบราว์เซอร์เอง
`start.ps1` เรียกตัวเปิดเดียวกัน ส่วน task `Dev: backend` และ `Dev: frontend` ยังมีให้ใช้แยกเมื่อต้องแก้ปัญหา

## เปิดเว็บจากไฟล์ Build

หากต้องการรันเฉพาะ Backend ที่เสิร์ฟหน้าเว็บ Build:

```powershell
npm.cmd --prefix frontend run build
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

เปิด http://127.0.0.1:8000 ระบบนี้ยังไม่ได้เผยแพร่สู่เว็บสาธารณะ
ฐานข้อมูลและ PDF ที่อัปโหลดสร้างใหม่ใน data/ ของแต่ละเครื่อง ไม่แชร์ผ่าน Git

## ทดสอบ

```powershell
.\.venv\Scripts\python.exe -m pytest backend -q
npm --prefix frontend run build
```

Backend tests ใช้ PDF fixture, temporary database และ mock provider ไม่เรียก Gemini จริง
GitHub Actions ตรวจ Backend และ Frontend ทุก push และ pull request

## AI และหลักฐาน

ใส่ Key ในเมนูตั้งค่า AI ของแอปเท่านั้น ห้ามใส่ในแชต โค้ด screenshot หรือ commit
Key อยู่ในหน่วยความจำ Backend; ปิด server แล้วต้องใส่ใหม่
ก่อนเรียก Gemini ต้องได้รับอนุญาตและกำหนดโควตา/งบ ไม่รับรองว่าบัญชีเป็น free tier
ระบบไม่สร้างคำตอบ AI เมื่อไม่มี Key

ตั้งจำนวนเรียกสูงสุดในเมนู AI (เริ่มต้น 3 ครั้ง) ทุกคำขอที่ส่งไป Gemini รวมคำขอที่ล้มเหลวใช้โควตา 1 ครั้ง
ผลเดิมจาก cache ไม่ใช้โควตาและไม่มีการลองซ้ำอัตโนมัติ จำนวนนี้เป็นข้อจำกัดต่อรอบการตั้งค่าในหน่วยความจำ
ตั้งค่าใหม่หรือเริ่ม Backend ใหม่จะเริ่มตัวนับใหม่ ไม่ใช่วงเงินค่าใช้จ่ายของบัญชี Google

ค้นด้วย keyword และคำแปลศัพท์ไทย/อังกฤษ ยังไม่มี semantic embeddings
เลขหน้าเป็นลำดับหน้า PDF เริ่มที่ 1 อาจต่างจากเลขหน้าที่พิมพ์ในรายงาน
การตรวจ quote ตรงกับข้อความไม่ได้รับรองว่าคำตอบถูกต้อง ต้องให้คนตรวจหลักฐาน
การเปรียบเทียบ Apple/Microsoft FY2025 ต้องระบุวันสิ้นสุดรอบบัญชีของแต่ละบริษัทที่ต่างกัน

## สถานะหลักฐานเดิม

บันทึกเดิมระบุ Backend tests ผ่าน 7 ข้อ และค้นหน้าที่มีเฉลยได้ 16/16 ข้อ
จาก Apple PDF 80 หน้าและ Microsoft PDF 158 หน้า (แปลงจาก DOCX ทางการ)
ยังไม่มีผลคุณภาพ AI หรือการทดลองผู้ใช้จริง ตัวเลขนี้ไม่ใช่คะแนนความถูกต้อง AI
ไฟล์หลักฐานเดิมและเอกสารวิจัย 20 เรื่องอยู่ใน workspace โครงงานเดิม ไม่รวมใน repo นี้

## วิเคราะห์และกราฟ

เมนูวิเคราะห์และความเสี่ยง: เลือกรายงานสูงสุด 2 ฉบับ ดูรายได้ กำไรสุทธิ กำไรจากการดำเนินงาน และ R&D สามปี พร้อมวันสิ้นสุดรอบบัญชี เลขหน้า และข้อความอ้างอิง
อัตรากำไรสุทธิคำนวณจากกำไรสุทธิหารรายได้ของบริษัทและปีเดียวกัน ไม่เรียก AI
ตัวสกัดรองรับเฉพาะงบข้อความภาษาอังกฤษสามคอลัมน์ หน่วย millions และเครื่องหมาย $; หากไม่รองรับจะไม่สร้างกราฟหรือเติมศูนย์ ต้องตรวจสกุลเงินจริงจากต้นฉบับ

โหมดคริปโต: ค้นหลักฐานเรื่องเทคโนโลยี Token supply Governance Security และ Risk จาก whitepaper ที่ผู้ใช้เลือก เป็น keyword search ไม่ใช่คะแนนความเสี่ยง

เมนูราคาหุ้นและคริปโต: เลือก AAPL, MSFT, BTC-USD หรือ ETH-USD ย้อนหลัง 1 เดือน 3 เดือน หรือ 1 ปี
ดึงราคาจาก Yahoo Finance public chart endpoint แบบไม่ใช้ Key มี cache 15 นาที แหล่งนี้ไม่มี SLA และอาจจำกัดการเข้าถึง
แสดงราคาปิดรายวัน ไม่ปรับปันผลหรือแตกหุ้น ไม่ใช่ข้อมูลเรียลไทม์และไม่ใช่ผลตอบแทนรวม วันที่แสดง UTC
ไม่มีการส่ง Gemini Key ไปยังผู้ให้บริการราคา ไม่แสดงข้อมูลจำลองเมื่อโหลดล้มเหลว และไม่มีการเรียก Gemini ในฟังก์ชันเหล่านี้
